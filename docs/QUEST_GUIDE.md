# Quest 3 연결 가이드 (목차)

로봇에 따라 두 가이드로 나뉜다. 각각 처음 쓰는 날 순서대로 따라가면 되도록 자기완결적으로 썼다.

| 상황 | 문서 |
|---|---|
| 로봇 없이 **Isaac Sim 4.2**로 연습 | [`GUIDE_QUEST_ISAAC.md`](GUIDE_QUEST_ISAAC.md) |
| **실제 UR5e**에 연결 | [`GUIDE_QUEST_REAL_ROBOT.md`](GUIDE_QUEST_REAL_ROBOT.md) |

공통 사항
- 인터넷은 필요 없다. PC와 Quest(실기는 로봇까지)가 같은 LAN이면 된다. 폰 핫스팟은 데이터를 꺼도 된다.
  Quest에 인터넷 되는 다른 저장 Wi-Fi가 있으면 그쪽으로 넘어갈 수 있으니 현장에서는 잊기 처리.
- Quest에 설치할 것은 없다. 브라우저로 `https://<PC-IP>:8765`를 열고 Start AR. 인증서 경고는 "고급 → 계속".
- PC 방화벽에서 8765 포트를 한 번 열어 둔다.
- 조작·메뉴 상세는 `OPERATION.md`, 헤드셋을 벗고 쓰는 방법도 거기에.
- 개발자 모드·adb는 헤드셋을 벗고 쓸 때(선택)만 필요: `META_DEVELOPER_SETUP.md`.
