Quest 3 → UR5e teleop

Quest 브라우저에서 이 페이지를 열고 Start AR(패스스루) 또는 Start VR을 누르세요.

기본 조작(헤드셋을 벗어도 됨): 오른손 그립(중지 버튼)을 쥔 채 움직이면 로봇 TCP가 위치·회전을 그대로 따라옵니다. 트리거 = 그리퍼, B = 즉시 정지. 표시 좌표는 TCP(그리퍼 손끝 중심).
헤드셋 착용 시: A(또는 썸스틱 클릭) → 옵션 메뉴(초기 자세로, 회전 추종, 튜토리얼, 보정, 축 고정, 녹화/재생, 배율, Isaac 카메라 오버레이(천장/사이드/EE), Isaac 시점 전환, 홀로그램, 경로 지우기). 스틱 위/아래로 이동, A 선택, B 닫기.
AR 홀로그램: 처음 그립을 쥐면 반투명 UR5e가 툴을 손에 맞춰 나타나고 실제 관절 각도로 움직입니다. 그립 중 TCP 경로(하늘색)와 손 경로(주황)가 그려집니다. 메뉴 "홀로그램 손에 맞추기"로 다시 정렬.
